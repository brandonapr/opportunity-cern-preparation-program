# opportunity-cern-preparation-program
## Descipción
Repositorio dedicado a documentar los esfuerzos en la preparación para ingresar en el programa de pasantías del CERN.

## Objetivo
Desarrollar habilidades críticas para facilitarme el desenvolvimiento de actividades una vez dentro del programa, familiarizandome con las herramientas utilizadas y los datos manejados habitualmente, con el fin de aumentar las probabilidades de ser seleccionado

## Áreas que Deseo Fortalecer
El uso de contenedores y cubernetes, manejo de redes informáticas y cnocimientos generales de física.
